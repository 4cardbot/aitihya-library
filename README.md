# Aitihya Research Library

This public repository contains selected research, business plans and operating documents for **Aitihya**, the research-led Indian textile design house, with **Pramāṇa** as its provenance and product-certification layer.

The formatted reading site is intended for collaborators, advisors and prospective partners who do not need access to the private Aitihya application repository.

Open the [Aitihya Research Library](./index.md) or browse the [research](./research/) and [business plans](./business_plans/) directories.
